# ClassWatch Chrome Extension (Manifest V3)

This extension connects a student's Chrome browser directly with their teacher's ClassWatch classroom monitoring dashboard.

## Privacy First
- **Only Active Hostnames**: Sends domain names only (e.g., `wikipedia.org`).
- **Never Full URLs**: Paths, search queries, and document IDs are stripped.
- **No Keystrokes or Webcams**: Zero surveillance of keystrokes, personal messages, or webcam video.

## How to Install (Chrome / Brave / Edge)
1. Open Google Chrome (or any Chromium browser).
2. Navigate to `chrome://extensions` in your address bar.
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `extension` folder inside this project directory.
6. Click the ClassWatch icon in your Chrome toolbar, enter your Student ID and the 4-digit class code provided by your teacher, and click **Connect**.
